# wb-bot-model-fallback

Плагин Discourse: ответы ИИ-бота генерирует запасная, более дешёвая модель, когда пользователь за
последние 24 часа сделал больше заданного числа обращений к модели.

## Зачем

Основную часть расхода на бота дают единичные очень длинные диалоги: сотни ответов одному
пользователю за день. Штатные квоты Discourse AI (`LlmQuota`) тут не помогают: при превышении они
отказывают в ответе, а токены считают без кэша, то есть у модели на Responses API видят лишь малую
долю реального объёма.

## Как работает

- Порог считается в **вызовах модели** за скользящие 24 часа по журналу `AiApiAuditLog`. Один ответ
  бота — обычно 3–4 вызова: поиск по базе знаний и сам ответ. Считаются личные диалоги с ботом
  (`feature_name = bot`) и ответы автоматизаций; заголовки тем, суммаризация и прочее — нет.
- При достижении порога модель подменяется на один ответ в `Playground#reply_to` — общий путь
  личных диалогов, упоминаний и автоматизаций. Агент, промпт и инструменты не меняются.
- Discourse сохраняет зашифрованные рассуждения модели вместе с вызовами инструментов и отправляет их
  обратно в следующих ответах той же переписки, не привязывая к модели. Плагин на время ответа
  убирает из истории рассуждения постов, сгенерированных другой моделью (поле `ai_llm_model_id`).
  Посты той же модели не трогаются, так что без переключений поведение прежнее.
- Каждое переключение пишется в `production.log`: `[wb-bot-model-fallback] topic=… user=… calls_24h=…`.

## Настройки (Админка → Настройки → Плагины)

| настройка | по умолчанию | смысл |
|---|---|---|
| `wb_bot_model_fallback_enabled` | выключено | главный выключатель |
| `wb_bot_model_fallback_daily_calls` | 40 | порог вызовов за 24 часа (40 ≈ 12 ответов бота) |
| `wb_bot_model_fallback_llm` | пусто | запасная модель; пусто — плагин ничего не меняет |

## Проверка

- `spec/` — 21 пример на Discourse 2026.7.1: выбор модели, отбор рассуждений, сквозной ответ через
  `Playground`. Мутации ловятся: без отбора рассуждений падают 3 примера, без порога — 4.
- Сквозная проверка на тестовом портале через заглушку Responses API, без обращений к OpenAI: переключение
  на запасную модель и обратно, каждой модели уходят только её собственные рассуждения.

Установка на прод — строкой `git clone` в `app.yml` и перезапуском unicorn, как у других плагинов WB.
